# Dragon_assistant
> **Dragon + LLM and made by AI**

Интерактивный голосовой и текстовый ассистент-питомец поверх всех окон для Windows, совмещающий физику экранного персонажа и интеллект локальной нейросети (LM Studio / Ollama).

---

## 📌 Что это такое?

**Dragon_assistant (Игнис)** — это умный настольный компаньон, летающий поверх всех окон Windows. Проект объединяет:
1. **Графический движок и физику (PyQt5 + Win32 API):** плавное парение по синусоиде, посадка на рамки окон и нижнюю панель задач, инерция, перетаскивание окон лапками, резкий бросок к курсору.
2. **Локальный искусственный интеллект (LM Studio / Qwen):** живое общение с собственным саркастичным и озорным характером, двухконтурная обработка запросов (отделение команд от беседы) и долговременная память с метками времени.
3. **Глубокую интеграцию с Windows:** автоматический сбор абсолютных путей ко всем установленным программам на диске, запуск любых приложений без ошибок UAC, сворачивание/закрытие окон, регулировка звука и создание скриншотов.
4. **Интерактивную настройку в реальном времени:** графическая панель со слайдерами (ползунками) для мгновенной регулировки скоростей, размеров, цветов и параметров ИИ без перезапуска приложения.

## 📁 Структура проекта

Состав файлов согласно рабочей директории:

```text
dragon/
├── main.py                # Главная точка входа: оверлей, физический цикл, HUD, звук
├── brain.py               # Логический центр: память диалога, роутинг команд и клиент LM Studio
├── app_scanner.py         # Модуль сканирования дисков, сбора абсолютных путей к .exe и запуска ПО
├── settings_ui.py         # Интерактивное окно настроек с ползунками (QSlider)
├── settings.json          # Конфигурация: физика, цвета HUD, размер, модель LLM и промпт
├── commands_config.json   # Конфигурация: правила распознавания команд, синонимы, ярлыки
├── requirements.txt       # Список внешних Python-зависимостей
├── create_shortcut.bat    # Скрипт создания тихого ярлыка запуска на Рабочем столе
├── apps_cache.json        # База собранных абсолютных путей к .exe (создается автоматически)
├── chat_history.json      # История переписки с временными метками (создается автоматически)
└── dragon.log             # Подробный лог работы, событий и ошибок (создается автоматически)
```

## ⚙️ Системные требования

* **ОС:** Windows 10 или Windows 11 (64-bit).
* **Python:** версия 3.10, 3.11 или 3.12.
* **Микрофон:** настроенный рабочий микрофон для голосового ввода.
* **Локальный сервер LLM:**
  * Установленная программа **[LM Studio](https://lmstudio.ai/)** с загруженной моделью (рекомендуется `qwen/qwen3.5-9b` или аналогичная) либо **Ollama**.

## 🚀 Как запускать?

### Шаг 1. Подготовка нейросети в LM Studio
1. Запустите **LM Studio** и перейдите во вкладку **Developer / Local Server** (значок `<->` слева).
2. Выберите и загрузите модель (например, `qwen/qwen3.5-9b`).
3. В правой панели настроек сервера отключите режим рассуждений (**Thinking / Reasoning: OFF**), чтобы модель отвечала сразу, без задержек.
4. Нажмите **Start Server**. Убедитесь, что сервер слушает порт `1234` (по умолчанию `http://127.0.0.1:1234` или сетевой IP, указанный в `settings.json`).

### Шаг 2. Установка зависимостей
Откройте консоль (PowerShell или CMD) в папке проекта и установите библиотеки:
```powershell
pip install -r requirements.txt
```

### Шаг 3. Запуск приложения

Есть два удобных варианта запуска:

#### Вариант А. Через тихий ярлык на Рабочем столе (Рекомендуется)
1. Запустите файл `create_shortcut.bat` двойным кликом.
2. Скрипт проверит окружение и создаст на Рабочем столе ярлык **«Дракон Игнис»**.
3. Запустите созданный ярлык — дракон стартует через фоновый процесс `pythonw.exe` без лишних черных консольных окон.

#### Вариант Б. Напрямую через консоль
```powershell
python main.py
```

## 🎯 Что ожидать после запуска?

1. **Запрос прав Администратора (UAC):**  
   Windows запросит повышение привилегий. Это необходимо, чтобы дракон мог взаимодействовать с окнами системных программ (Диспетчер задач, консоли, защищенные редакторы).
2. **Диалоговое окно имени:**  
   Появится небольшое окно с вопросом: *«Как обращаться?»* (по умолчанию введено имя из конфига). Введите имя и нажмите Enter.
3. **Элементы на экране:**
   * **Дракончик:** летает по экрану с анимацией крыльев. Не врезается в края монитора, а плавно отталкивается от них. Его можно хватать левой кнопкой мыши и перетаскивать.
   * **HUD-терминал в правом нижнем углу:**
     * `🎙️` — кнопка временного отключения микрофона (Mute).
     * `⚙️` — кнопка открытия панели настроек с ползунками.
     * `💬` — свернуть/развернуть окно переписки в тонкую полоску.
     * `❌` — моментальное безопасное выключение программы.
     * **Поле ввода (внизу чата):** позволяет отдавать команды и общаться текстом без голоса.
4. **Сбор путей программ:**  
   При первом запуске модуль `app_scanner.py` просканирует реестр и меню «Пуск», создав файл `apps_cache.json`. Дракон сообщит в чат, сколько сотен приложений он нашел.

## 💬 Команды и взаимодействие

Вы можете говорить голосом в микрофон или печатать в строке ввода HUD:

### 1. Запуск приложений по абсолютным путям
* *«Открой Телеграм»* / *«Запусти Дискорд»* / *«Вруби Фотошоп»* / *«Открой Стим»*
* *«Открой Блокнот»* / *«Запусти Калькулятор»* / *«Включи Paint»* / *«Открой браузер»*

### 2. Управление окнами и рабочим столом
* *«Сверни все окна»* / *«Рабочий стол»* — чистое сворачивание всех окон (`Win + D`).
* *«Сверни окно»* — свернуть текущее активное окно.
* *«Разверни окно»* — развернуть окно на весь экран.
* *«Закрой окно»* — закрыть активное приложение.
* *«Перетащи окно»* — дракон подлетает к окну, берет его в лапы и тащит по экрану.

### 3. Поведение дракона и взаимодействие с мышью
* *«Где мышка»* / *«К мышке»* — быстрый стремительный рывок дракона прямо к курсору.
* *«Сядь на окно»* — дракон ищет активное окно и приземляется на его верхнюю рамку.
* *«На землю»* / *«Вниз»* — спускается на панель задач и гуляет там.
* *«Взлетай»* / *«Вверх»* — возвращается в режим свободного парения.
* *«Спать»* — ищет ближайшую опору, ложится и храпит 💤.
* *«Поешь»* — приземляется и хрустит угольками 🔥.
* *«Брось»* / *«Отпусти»* / *«Фу»* — моментальная отмена удержания мышки/окна.

### 4. Мультимедиа, система и поиск
* *«Пауза»* / *«Плей»* — переключение воспроизведения видео/музыки.
* *«Громче»* / *«Тише»* / *«Выключи звук»* — регулировка звука Windows.
* *«Скриншот»* — сохранение снимка экрана прямо на Рабочий стол.
* *«Заблокируй компьютер»* — быстрая блокировка системы (`Win + L`).
* *«Загугли рецепт пиццы»* / *«Найди в интернете погоду»* — открывает страницу поиска в браузере.
* *«Выключись»* / *«Закройся»* — выгружает ассистента из памяти.

### 5. Свободное общение
Любая фраза, не являющаяся командой, отправляется напрямую в нейросеть. Игнис помнит предыдущие реплики, время разговора и отвечает живым текстом с легкой иронией, без роботизированных приветствий.

## 🎛️ Панель настроек (Кнопка `⚙️`)

Открывает окно с ползунками, работающими на лету:
* **Скорость парения** — базовый темп свободного полета.
* **Скорость рывка к мыши** — динамика подлета к курсору.
* **Маневренность (инерция)** — плавность поворотов и торможения.
* **Размер дракона** — габариты спрайта под разрешение монитора.
* **Амплитуда волн** — высота взмахов крыльев.
* **Непрозрачность HUD** — прозрачность темной темы чата.
* **Память диалога** — количество запоминаемых реплик.
* **Температура ИИ** — креативность и экспрессивность ответов модели.
* **Выбор цветов** — палитра для рамки, текста и статусов.
* **Пересобрать пути к .exe** — повторный обход системы при установке новых игр и программ.
