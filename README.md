# Настольный дракончик Игнис 🐲

Живой питомец поверх всех окон Windows: летает по экрану, разговаривает через локальную
нейросеть (LM Studio), понимает голосовые и текстовые команды вида «игнис, открой блокнот»,
управляет окнами, громкостью, скриншотами и блокировкой ПК. Все настройки меняются «на живую»
через кнопку ⚙️ прямо в интерфейсе — без перезапуска и без правки кода.

- **Физика персонажа (PyQt5 + Win32 API):** плавное парение по синусоиде, инерция, посадка на
  рамку активного окна и на «пол» экрана, ходьба по окну, перетаскивание окна лапками, рывок к курсору.
- **Локальный интеллект:** двухконтурная обработка — сначала быстрый поиск системной команды,
  если её нет — живой диалог с моделью и памятью разговора. Работает и без нейросети.
- **Интеграция с Windows:** автоматический сбор абсолютных путей ко всем .exe на ПК, запуск любых
  программ, системные протоколы (`ms-settings:`, `calculator:`, `outlookcal:`).
- **Настройки из интерфейса:** ползунки скорости, размера, цветов, памяти диалога и температуры LLM.

---

## Быстрый запуск (Windows)

```cmd
.\run.bat
```

Скрипт сам создаст окружение на Python 3.12 (`.venv`), установит зависимости из
`requirements.txt` и запустит `main.py`. Если `.venv` уже есть, но создан на другой версии
Python или сломан — `run.bat` пересоздаст его автоматически.

**Про права администратора.** Программа при старте сама запрашивает повышенные привилегии
(они нужны для управления окнами через Win32 API) и перезапускается — согласитесь в окне UAC.
Окно консоли после этого можно закрыть, дракон продолжит работать.

## Ручная установка (Linux / macOS или без run.bat)

```bash
py -3.12 -m venv .venv          # Linux/macOS: python3.12 -m venv .venv
source .venv/Scripts/activate   # Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Проект проверяется на **Python 3.12**: на более новых версиях установка `PyAudio`
(нужен для голосовых команд) может потребовать ручной сборки. Все версии пакетов
зафиксированы в `requirements.txt`; полный проверенный набор — в `requirements-lock.txt`
(`pip install -r requirements-lock.txt`), если после обновления пакетов что-то сломалось.

## Что происходит при первом запуске

1. Окно UAC — согласовать права администратора.
2. Если `settings.json` ещё нет, он создаётся автоматически из шаблона `settings.example.json`
   (в шаблоне нет персональных данных, адрес LM Studio по умолчанию `http://127.0.0.1:1234`).
3. Диалог «Как обращаться?» — имя сохраняется в `settings.json` и показывается в чате.
4. В правом нижнем углу появляется чат-панель (HUD) и сам дракон; в логе видно, сколько
   программ найдено на компьютере.
5. Голос — скажите «игнис, …» и команду, либо напишите её в поле внизу панели.

Кнопки в шапке панели: 🎙️ микрофон вкл/выкл, ⚙️ настройки, 💬 свернуть/развернуть чат, ❌ выход.

## Команды

Обращение в начале фразы не обязательно, но работает надёжнее: «игнис, открой калькулятор».
Все формулировки и правила — в `commands_config.json`, их можно менять самому.

| Тема | Примеры |
|---|---|
| Программы | «открой блокнот», «запусти телеграм», «вруби фотошоп», «зайди в настройки» |
| Интернет | «найди в интернете погоду», «загугли python venv», «открой ютуб» |
| Окна | «сверни окно», «разверни на весь экран», «закрой окно», «перетащи окно», «сверни всё» |
| Полёт и поведение | «взлетай», «на землю», «сядь на окно», «к мышке», «отпусти», «спи», «кушать» |
| Система и медиа | «скриншот», «заблокируй компьютер», «пауза», «громче», «тише», «без звука» |
| Выход | «выключись», «отключись», «выход» |
| Диалог | любая обычная фраза — дракон ответит характером и вспомнит контекст разговора |

## Настройка под себя — всё из интерфейса

Нажмите **⚙️** в шапке чата:

- скорость парения, скорость рывка к мыши, маневренность (инерция);
- размер дракона и амплитуда «волн» полёта;
- непрозрачность панели чата, глубина памяти диалога, креативность модели (temperature);
- цвета рамки и реплик;
- «🔄 Пересобрать пути к .exe» — обновить базу программ после установки новых.

Изменения применяются сразу и сохраняются в `settings.json`. Этот файл создаётся сам из
шаблона `settings.example.json` при первом запуске и в репозиторий не попадает (он в `.gitignore`) —
свой адрес модели, имя и цвета хранятся локально и не мешают другим.

| Файл | Что настраивается |
|---|---|
| `settings.example.json` | шаблон всех настроек (лежит в репозитории); при первом запуске из него создаётся `settings.json` |
| `settings.json` | твой рабочий файл: адрес и модель LM Studio, имя и характер дракона, скорости, размер, `sprite_file`, цвета HUD, глубина памяти, температура |
| `commands_config.json` | правила команд (регулярки и ответы), слова-обращения, триггеры «открой/запусти/найди», синонимы программ (`телега` → telegram), быстрые ссылки (ютуб, браузер) |

`dragon.gif` — анимированная гифка дракона. **Файла в репозитории нет**: без него дракон летает
со смайликом-иконкой. Положите свой `dragon.gif` рядом с `main.py` (путь задаётся в `settings.json`).

## Как дракон находит программы

`app_scanner.py` собирает **абсолютные пути к .exe** со всего компьютера:

1. системные утилиты (`System32`),
2. реестр: `App Paths` и раздел «Установленные программы» (`DisplayName` + `DisplayIcon`),
3. ярлыки `.lnk` из меню «Пуск» и с Рабочего стола (раскрываются в цель через `pywin32`),
4. обход `Program Files`, `Program Files (x86)`, `%LOCALAPPDATA%\Programs` (включая каталоги `app-` у Electron-приложений).

База кэшируется в `apps_cache.json` и загружается при следующем запуске; запуск программы идёт
строго по абсолютному пути (`subprocess.Popen` с рабочей папкой программы). Без `pywin32`
программа работает, но база будет беднее. Системные «Настройки», «Калькулятор», «Календарь»
открываются протоколами, если .exe не найден.

## Структура проекта

```text
.
├── main.py                 # точка входа: окно питомца, физика, состояния, HUD, голосовой ввод
├── brain.py                # ConfigManager, память диалога, разбор команд, клиент LM Studio
├── app_scanner.py          # база абсолютных путей к .exe и запуск программ
├── settings_ui.py          # окно ⚙️ с ползунками и живым применением
├── settings.example.json   # шаблон настроек (из него создается рабочий settings.json)
├── commands_config.json    # команды, синонимы и быстрые ссылки
├── requirements.txt        # зависимости (версии зафиксированы)
├── requirements-lock.txt   # полный проверенный набор версий
├── run.bat                 # окружение + запуск одной кнопкой
├── settings.json           # рабочие настройки (создается при первом запуске, в .gitignore)
├── apps_cache.json         # база путей к .exe (создается автоматически, в .gitignore)
├── chat_history.json       # история диалога с метками времени (создается автоматически, в .gitignore)
└── dragon.log              # лог работы и ошибок (создается автоматически, в .gitignore)
```

## Частые проблемы

| Симптом | Что делать |
|---|---|
| В консоли «Запрос прав Администратора…» и ничего не запустилось | Это штатно: согласитесь в окне UAC (или запустите `run.bat` от администратора) |
| Голосовые команды не работают | Нужен микрофон и пакет `PyAudio`; без него доступен только текстовый ввод |
| Дракон молчит или отвечает «не могу достучаться до LM Studio» | Не запущен LM Studio с API-сервером, либо в `settings.json` неверные `lm_studio_url` / `local_model`. Проверьте: `curl http://127.0.0.1:1234/v1/models` |
| Не находит программу | ⚙️ → «🔄 Пересобрать пути к .exe», или добавьте синоним в `app_aliases` в `commands_config.json` |
| Русские буквы превратились в кракозябры | В `run.bat` уже стоит `chcp 65001`; логи и история диалога пишутся в UTF-8 |
| После обновления пакетов что-то перестало работать | `pip install -r requirements-lock.txt` |

## Требования

- Windows 10 (используются Win32 API: `user32`, `winreg`; опционально `pywin32`)
- Python 3.12 (на этой версии проверяется установка)
- Для диалога — запущенный LM Studio (или любой OpenAI-совместимый сервер) с включённым API
